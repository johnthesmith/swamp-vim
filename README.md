# Still Swamp

A minimal Neovim config. No plugins, with system clipboard support.

## Features

- Insert-first workflow
- Esc toggles Insert/Normal
- Ctrl-based shortcuts in nano style
- Smart indentation
- Filetype-aware comments
- AI integration (ai-cli)
- Cyrillic keyboard layout support

## Installation

```bash
git clone https://github.com/yourname/swamp-nvim ~/.config/nvim
```

or copy `init.vim` to `~/.config/nvim/`.

## Requirements

- Neovim
- [ai-cli](https://github.com/johnthesmith/ai-cli) (optional, for Alt+1/Alt+2)
